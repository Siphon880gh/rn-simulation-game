# Sepsis / septic shock / MODS cheat guide

Fictional teaching aid for the RN Shift Simulator. Not a substitute for facility protocol or Surviving Sepsis Campaign full text.

## Quick screen (qSOFA-style red flags)

Think **infection + new organ stress**:

| Flag | Teaching cue |
|------|----------------|
| Altered mentation | New confusion, delayed answers, obtunded |
| RR ≥22 | Tachypnea / work of breathing |
| SBP ≤100 | Relative hypotension for the patient |

Also watch fever **or** hypothermia, tachycardia, oliguria, mottled/cool skin, rising lactate.

## Sepsis

**Suspected/known infection** plus **acute organ dysfunction** (e.g. new confusion, lactate up, Cr rise, hypoxemia, thrombocytopenia).

**Hour-1 bundle priorities (sim):**

1. Measure **lactate**
2. Obtain **blood cultures** before antibiotics when possible
3. Rapid **IV crystalloid** (teaching target **30 mL/kg**) for hypotension or lactate ≥4
4. Broad-spectrum **empiric antibiotics** promptly
5. Reassess vitals / mentation / urine output

## Septic shock

Sepsis **plus** circulatory / cellular failure:

- Persistent **hypotension** needing fluids / vasopressors (MAP goal teaching cue **≥65**), and/or
- **Lactate ≥2 mmol/L** despite adequate volume resuscitation

**Extra actions:** notify provider early, prepare for **vasopressors** if MAP stays low after fluids, **repeat lactate**, support airway/O₂.

## MODS (multiple organ dysfunction)

Failure / severe dysfunction in **≥2 organ systems** (e.g. neuro + CV + renal + respiratory + heme/liver). Treat as **highest acuity** — full bundle, rapid escalation, multi-organ support huddle.

## Classification cheat

| Pattern | Classify as |
|---------|-------------|
| Infection risk but stable VS / mentation / lactate | No sepsis — continue monitoring |
| Infection + organ dysfunction (qSOFA-like) | Sepsis — start hour-1 bundle |
| Sepsis + lactate ≥2 or fluid-refractory hypotension | Septic shock — bundle + escalate |
| ≥2 failing organs with shock physiology | MODS — multi-organ support / escalate |
